Haps · internal spec

How events are classified and scored

Flow + criteria
3 Oct 2026

There is no genre taxonomy. No house vs afro vs comedy buckets. Classification is one number: noul, 0–1, from TypeSafe Jev answering a yes/no-style question. Two separate Jev jobs run at different times.

End-to-end flow

Apify scrape (Luma / Posh / Dice) → flatten into listings (title, city, venue, time, image, url) → Jev keep-score each listing → store keep_score User texts Haps → Claude calls search_events → if kept listings exist for that city: return those (no extra rank) → else: rank the seed catalog with Jev against the user's ask → iMessage: “Here's what I found” + flyer album

Ingest runs about 20 seconds after boot, then every 6 hours if APIFY_TOKEN is set. Cap is 15 items per source per city.

The two scores

1 · Ingest keep

0.55 gate · nightlife or not

After upsert, each listing is sent to Jev in chunks of 8.

Question. Is this a real upcoming night out (party, club, concert, social) someone should get recommended?

Reject. Movies, ads, party vendors, vague lifestyle posts.

Jev sees. Title, city, venue, start time, first 240 characters of description. Not the flyer image.

Output. keep_score on the row (0–1). Missing API key skips scoring.

Serve gate. keep_score ≥ 0.55 and starts_at still in the future, then city match (NYC ↔ New York, Miami, etc.). Limit 40, soonest first.

There is no second pass against “afrobeats this weekend.” If listings exist, they win. Query and tags are unused.

2 · Catalog rank

0.55 gate · match the ask

Only if there are zero kept listings for that city.

Jev scores every seed events row against query + tags + city.

Question. Should Haps recommend this for someone looking for {ask}? Prefer vibe and city match.

Keep. noul ≥ 0.55. If nothing clears that, return the top 2. If Jev is down, return the full catalog.

Criteria at a glance

Step Hard rule Soft judgment (Jev)
Normalize Must have a title and URL. Source-specific field mapping. None
Ingest score None besides the prompt Real night out vs movie / ad / vendor / lifestyle post
List for recs keep_score ≥ 0.55, future start, city alias match, max 40 None. User query is not re-scored.
Catalog fallback noul ≥ 0.55, else top 2 Fit to the user's ask, vibe, and city

What is not scored

  • Taste (likes / dislikes) is stored and shown to Claude. It is not in the Jev questions.
  • Claude does not score events. It may only recommend what search_events returned.
  • No genre labels. Tags on listings come from the scraper when present. Jev does not assign them.
  • Images are not scored. Flyers are whatever URL is on the kept row.

The 0.55 cutoff is the only numeric criterion. Everything else is the prompt plus Jev’s 0–1 judgment.
